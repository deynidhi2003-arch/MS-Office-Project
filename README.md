# Computer Training Center Leaflet Design

## Project Overview
This project showcases a professional promotional leaflet designed for the "Bansberia Youth Computer Training Center". The goal was to create a clean, visually appealing, and structured flyer to attract students for the upcoming academic session.

## Tools & Skills Used
- **Tool:** MS Word / MS Office Suite
- **Skills:** Layout Design, Content Hierarchy, Typography, Visual Alignment.
